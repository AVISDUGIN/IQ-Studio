# IQ Studio

واجهة عربية متجاوبة لإدارة بطولات IQ Studio وبرامجه وأخباره. تتم المصادقة عبر Supabase Auth، وتُحفظ ملفات المستخدمين والمقاطع والبرامج والتنزيلات والأخبار والبث في جداول Postgres مع سياسات Row Level Security (RLS). لا يستخدم التطبيق ملف store.json أو ملفاً محلياً لحفظ بيانات الموقع.

## المتطلبات

- Node.js 20 أو أحدث.
- مشروع Supabase.
- رابط المشروع ومفتاح anon أو publishable من إعدادات API.

## التشغيل

1. ثبّت الاعتمادات باستخدام npm install.
2. انسخ .env.example إلى ملف جديد اسمه .env (لا تضع بياناتك في ملف المثال وحده)، واستبدل الرابط https://your-project.supabase.co بالرابط الحقيقي من Supabase Project Settings → API. احتفظ بمفتاح anon أو publishable في المتغير:
   - SUPABASE_URL
   - SUPABASE_ANON_KEY (يمكن وضع مفتاح anon أو المفتاح العام publishable هنا).
3. في Supabase Dashboard → SQL Editor، شغّل محتوى supabase/schema.sql.
4. من إعدادات Supabase Auth، فعّل التسجيل وأوقف تأكيد البريد الإلكتروني؛ لأن الدخول في هذه الواجهة يستخدم اسم المستخدم من دون طلب بريد فعلي.
5. شغّل محلياً باستخدام npm run dev، ثم افتح العنوان الذي يظهر في الطرفية.
6. للإنتاج: نفّذ npm run build ثم npm start. اضبط متغيرات البيئة في منصة الاستضافة؛ لا يلزم وجود قرص قابل للكتابة للتطبيق.

## إنشاء حساب المدير الأول

أنشئ الحساب من نموذج التسجيل ببيانات المدير التي حددتها في طلبك: اسم المستخدم iq2011 وكلمة المرور المحددة هناك. بعد تشغيل المخطط، نفّذ في SQL Editor:

    update public.profiles
    set roles = array['admin']
    where username = 'iq2011';

بعد ذلك سجّل الخروج ثم الدخول مجدداً حتى تُحمّل رتبة المدير. لم تُضمّن كلمة المرور في ملفات المشروع. يمكن لمدير لاحق منح رتبة viewer_admin أو إنشاء رتب مخصصة من لوحة المطور.

## الصلاحيات

- يستطيع الزائر مشاهدة البرامج والمقاطع والأخبار العامة. لا يحصل الزائر على سجل البث أو روابط التنزيل.
- يحتاج البث إلى حساب مسجل، وتُفحص صلاحية قسم البطولات في RLS.
- تحفظ بيانات وصف البرنامج في جدول programs، بينما تحفظ روابط التنزيل في جدول program_downloads ولا تُقرأ إلا من المستخدمين المسجلين الذين لديهم صلاحية تنزيل البرامج.
- تُحفظ الرتب والحظر والأقسام المقفلة في جدول profiles. تُنفذ تغييرات إدارة الحسابات عبر دوال SQL تتحقق من صلاحية المدير.
- رتبة viewer_admin تسمح بفتح لوحة المطور وقراءة محتواها فقط. صلاحيات التعديل والحذف مفروضة في RLS ودوال قاعدة البيانات أيضاً.
- لكل رتبة وصف يظهر كتلميح عند المرور عليها، ويمكن تعيين أكثر من رتبة للحساب.
- يسجل record_my_login() وقت آخر دخول بدقة قاعدة البيانات، ويُعرض بالتوقيت المحلي للجهاز.

## ملاحظات نشر وأمان

SUPABASE_ANON_KEY مفتاح عام يرسله التطبيق للمتصفح؛ تعتمد الحماية على RLS والدوال المعرفة في المخطط. لا تضع مفتاح service_role أو أي مفتاح سري في .env الخاص بالواجهة أو في متغيرات تُرسل للمتصفح. يحتفظ خادم Express بمسارات تقديم الملفات و/api/config فقط، وتذهب عمليات البيانات مباشرة إلى Supabase مع جلسة المستخدم وسياسات قاعدة البيانات.

البث يفتح رابط المنصة الخارجية في تبويب جديد بعد قراءة بياناته من Supabase؛ اختيار رابط TikTok أو منصة أخرى يتم من لوحة المطور. المقاطع عامة وروابطها الخارجية تُفتح في تبويب مستقل.
